# Security Policy

## Supported Surface

This repository is currently an active public documentation/static-site lane.
Security review focuses on:

- static HTML, CSS, and JavaScript behavior;
- dependency and CDN usage in static pages;
- accidental disclosure in business, legal, CRM, or financial templates;
- workflow and repository automation changes.

## Reporting a Vulnerability

Do not open a public issue for sensitive findings. Contact the repository owner
or org maintainers directly through the approved private channel.

When reporting, include:

- affected file or URL;
- reproduction steps;
- expected impact;
- whether secrets, customer data, or private business data may be exposed.

## Disclosure Boundary

The legal, tax, financial, and business-planning materials are templates and
working documents. Do not treat them as legal, financial, or tax advice.
